Privacy Policy

Last updated: May 12, 2026

Currio ("the Extension") is built with privacy as a core principle. This policy explains what data we handle and how.

1. Data Collection

Currio does not collect, store, or transmit any personal information. We do not use analytics, tracking pixels, or any form of user monitoring.

2. What the Extension Processes Locally

The Extension scans webpage text content to identify currency symbols and price patterns. All scanning, matching, and conversion rendering happens entirely within your browser. No page content is sent to any server.

3. Exchange Rate API

To fetch current exchange rates, the Extension makes requests directly from your browser to ExchangeRate-API (exchangerate-api.com). These requests contain only the base currency code (e.g., "USD") — no page data, no browsing history, no personal identifiers. Rates are cached locally for 45 minutes to minimize requests.

4. Permissions

Currio requests the following Chrome permissions:

  • Storage — to save your currency preference and cached exchange rates locally.
  • Active Tab — to scan the current page for currency patterns upon page load.
  • Host Permission (exchangerate-api.com) — to fetch exchange rate data.

5. Data Sharing

We do not share any data with third parties because we do not collect any data in the first place.

6. Children's Privacy

The Extension does not collect information from anyone, including children under the age of 13.

7. Changes to This Policy

If we update this policy, the revised version will be posted at this URL with an updated effective date.

8. Contact

For questions about this privacy policy, please open an issue at github.com/gaojice/currio/issues.
