What it does

It just works in the background.

No configuration needed. Install it and forget about it — Currio handles currency conversion automatically.

Recognizes prices everywhere

Works with $100, ¥1000, €50, £30, ₩50000, NT$690, HK$100 and many more formats across any website.

Figures out which currency

The $ symbol could mean USD, CAD, AUD or others. Currio uses page context, browser language and domain to figure it out.

Keeps rates current

Updates exchange rates every 45 minutes. If the API fails, it retries intelligently without bothering you.

Won't break websites

Uses CSS pseudo-elements instead of modifying the DOM. Works fine with React, Vue, Angular — any framework.

Sets itself up

Detects your preferred currency from your browser settings when you first install it. Ready to go immediately.

Respects your privacy

Doesn't track you, doesn't collect data, doesn't run analytics. Exchange rate requests go straight to the API.

Getting started

Takes about 30 seconds.

Install it, then just browse like you normally would. That's really all there is to it.

Install it

Get it from the Chrome Web Store. It'll automatically detect what currency you use.

Browse normally

Go to any website. Currio watches for prices as pages load and update.

See converted prices

Converted amounts show up right next to the original prices. Subtle enough that you barely notice them until you need them.
