Features

Built for zero-friction browsing.

Currio works silently in the background. You browse normally — it handles the rest.

Auto-Detect

Recognizes $100, ¥1000, €50, £30, ₩50000, NT$690, HK$100, and dozens more — on any website.

Smart Inference

$ maps to 6+ currencies. Currio resolves it from page locale, browser language, TLD, and surrounding context.

Always Fresh Rates

45-min TTL cache with exponential backoff on failures. Always shows current rates, never stale.

React-Proof

Renders via CSS ::after pseudo-elements — zero DOM mutations. Won't break any SPA or reactive framework.

Zero Config

Detects your preferred currency from browser language on first install. Works out of the box.

Privacy First

No tracking, no analytics, no data collection. Rate requests go directly to ExchangeRate-API.

How It Works

Three steps. That's it.

Install, browse, and let Currio do the math while you focus on what matters.

Install

Add Currio from the Chrome Web Store. It picks up your local currency automatically.

Browse

Visit any website. Currio scans the page and detects prices in real time as the DOM updates.

Read in Your Currency

Converted prices appear inline, right next to the original — barely noticeable until you need them.
